**69** (/ˌsɪksti ˈnaɪn/), read **sixty-nine**, is a slang term for a sex position in which both partners give each other oral sex at the same time. [Collins English Dictionary](https://www.collinsdictionary.com/us/dictionary/english/sixty-nine)

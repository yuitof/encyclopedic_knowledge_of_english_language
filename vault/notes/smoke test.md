**smoke test** (/ˈsməʊk ˌtest/) is a short preliminary check that a system's most critical functions work before it undergoes more thorough testing. In software development, a smoke test is often run after a build or deployment to decide whether the build is stable enough to test further.

Source: [TechTarget — What is smoke testing?](https://www.techtarget.com/searchsoftwarequality/definition/smoke-testing).

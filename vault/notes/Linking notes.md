# Linking notes

Use [[Writing notes|a displayed alias]] or [an ordinary Markdown link](Writing%20notes.md). Backlinks show which other notes refer to this article.

The graph uses these same article connections. Drag to pan, scroll to zoom, and select a vertex to open its article.

## Missing targets

[[Future topic]] demonstrates a missing note: the build creates a blank destination in temporary output. It does not create that file in your source vault. Missing image files are not replaced.

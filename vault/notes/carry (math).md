**carry** (/ˈkæri/) is a verb used in arithmetic for transferring a value to the next place-value column when a column’s sum or product is too large for one digit.

For example, in **27 + 15**, the ones give **7 + 5 = 12**. Write **2** in the ones column and **carry the 1** to the tens column. Then **2 + 1 + 1 = 4**, so the answer is **42**. The carried **1** represents one ten.

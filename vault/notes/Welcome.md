# Welcome

This is the sample vault. These example notes demonstrate the website without including the live collection in the working files.

Start with [[Writing notes]] and [[Linking notes]]. Their connections appear in the graph.

![[note-connections.png|Two connected notes]]

To preview another collection, set `VAULT_ROOT` to the checkout containing its `vault/` folder. For deployment, create your own `vault` branch from this starter; the website workflow deploys that branch, not `sample-vault`.

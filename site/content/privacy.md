This is a static website with no account system, advertising, or site analytics. Search runs in your browser after downloading the public note index.

Your appearance and article-order preferences are stored locally in your browser. Search may use temporary session storage to highlight a selected result. Clear site data in your browser to remove these settings. No preference data is sent to a separate application server.

GitHub Pages hosts the site and may process ordinary request information under [GitHub’s privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Links to other websites follow those sites’ policies. Images and scripts used by this site are served as static assets; following an external link may disclose a normal web request to that destination.

Only explicitly selected notes and images are included. Repository source and history have their own visibility settings; the website’s publication selection does not change repository access.
